# CLAUDE.md

This is a tool-agnostic project, worked on by contributors who don't all use
Claude Code. Read, in order:

1. [`ai-rules.md`](ai-rules.md) - behavioral rules for AI contributions on
   this project. Read this first, every session.
2. [`architecture.md`](architecture.md) - system design, including its
   "Codebase structure" section (conventions for where new code goes).
3. [`datamodel.md`](datamodel.md), [`userstories.md`](userstories.md),
   [`requirements.md`](requirements.md) - data model, feature backlog/status,
   and original requirements, as needed for the task at hand.

Recurring procedures live as skills in [`.claude/skills/`](.claude/skills/).
Claude Code discovers and loads them on demand - do not read them up front.

Nothing here duplicates those files - if something here and one of them ever
disagree, the file above wins and this one is stale.
